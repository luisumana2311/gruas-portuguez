# Grúas Portuguez — prototipo (fase 1)

React + Vite + Tailwind. Una sola página con datos de ejemplo.

- `npm install` y `npm run dev` para verla en local.
- `npm run build` genera `dist/` (incluye `public/_redirects` para Netlify).
- Datos editables en `src/data/sitio.js` (en fase 2 pasan a Firestore).
- Fotos de relleno en `public/img/` (SVG de ejemplo).

## Pendiente del cliente
Logo, fotos reales, textos finales, horario y datos para la ficha de Google.

## Fase 2 (tras aprobación)
Panel `/admin` con Firebase Auth, textos/teléfono/WhatsApp en Firestore, fotos de galería, JSON-LD generado desde los datos.
